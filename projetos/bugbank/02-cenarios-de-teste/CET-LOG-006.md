# CET-LOG-006 — Não deve autorizar o acesso para usuários inválidos ou não cadastrados.

**Dado** que estou na tela de acesso ao sistema do Bugbank  
**Quando** preencho o campo obrigatório e-mail com um e-mail não cadastrado/inválido  
**E** preencho a senha no campo obrigatório de senha  
**E** clico na opção "Acessar"  
**Então** o sistema não autoriza o acesso a uma área restrita da aplicação  
**E** permaneço na tela de acesso ao sistema

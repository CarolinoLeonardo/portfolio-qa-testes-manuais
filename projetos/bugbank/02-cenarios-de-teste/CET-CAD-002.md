# CET-CAD-002 — Cadastro de um novo usuário

**Dado** que estou na tela de cadastro de uma nova conta  
**Quando** preencho todos os campos obrigatórios com dados válidos  
**E** aciono a opção para cadastrar a conta  
**Então** o sistema deve exibir a notificação “A conta XXX-X foi criada com sucesso”  
**E** a conta deve ser criada  

## Observações do cenário

O e-mail utilizado não deve estar previamente cadastrado. A senha e sua confirmação devem possuir valores idênticos e atender às regras definidas no requisito.

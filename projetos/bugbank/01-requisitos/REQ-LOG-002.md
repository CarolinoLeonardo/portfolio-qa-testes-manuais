# REQ-LOG-002 — Indicação de obrigatoriedade dos campos de e-mail e senha

## Descrição

Na tela de login, os campos de e-mail e senha devem ser identificados visualmente como obrigatórios.

A indicação de obrigatoriedade deve ser apresentada por meio de um asterisco vermelho (*).

## Critérios de aceite

- O campo “E-mail” deve possuir uma indicação visual de obrigatoriedade.
- O campo “Senha” deve possuir uma indicação visual de obrigatoriedade.
- A indicação deve ser exibida junto ao rótulo de cada campo.
- A indicação pode ser apresentada por meio de um asterisco vermelho (*) ou pelo texto “Obrigatório”.
- A indicação deve estar visível antes que o usuário tente efetuar o login.
- Os dois campos devem utilizar o mesmo padrão visual de indicação.

## Exemplos

- **Válido:** os campos “E-mail” e “Senha” apresentam um asterisco vermelho (*) junto aos respectivos rótulos.
- **Inválido:** os campos “E-mail” e “Senha” não apresentam nenhuma indicação visual de obrigatoriedade.

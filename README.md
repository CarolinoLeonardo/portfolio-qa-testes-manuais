# Portfólio de QA — Testes Manuais

Este repositório reúne projetos práticos de **Quality Assurance**, desenvolvidos durante minha transição de carreira para a área de tecnologia.

O objetivo é aplicar e demonstrar conhecimentos relacionados ao planejamento, à documentação, à execução e ao acompanhamento de testes manuais.

---

## Projetos

| Projeto                               | Aplicação              | Tipos de teste                    | Status       |
| ------------------------------------- | ---------------------- | --------------------------------- | ------------ |
| [BugBank](projetos/bugbank/README.md) | Aplicação bancária web | Testes funcionais e exploratórios | Em andamento |

---

## Competências desenvolvidas

* Análise e documentação de requisitos;
* Planejamento de testes;
* Criação de cenários de teste;
* Elaboração e execução de casos de teste;
* Realização de testes exploratórios;
* Registro e classificação de defeitos;
* Organização de evidências;
* Rastreabilidade entre requisitos, testes e bugs.
